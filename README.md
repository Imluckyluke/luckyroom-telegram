# luckyroom-telegram

Telegram Web replica — **frontend UI only** for Luckyroom.

Live preview: GitHub Pages (root) → `index.html`

## Run locally
Open `index.html` in browser. No build, no backend.

## What's included
- Sidebar: search, stories, folders (All / Personal / Groups / Channels), chat list with unread / mute / pin / typing
- Chat window: header, pinned bar, date + service messages, text / photo / voice / file bubbles, reply (double-click), ticks
- Composer: attach, emoji picker, dynamic send, fake incoming reply
- Night / light mode, info panel, hamburger drawer, mobile responsive
